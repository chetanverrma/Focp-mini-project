# 🎯 Number Guessing Game

A simple and interactive Number Guessing Game developed using C Programming as part of our **FOCP (Fundamentals of Computer Programming) Mini Project.

The computer generates a random secret number, and the player has to guess it within a limited number of attempts. The game provides hints to guide the player towards the correct answer.

## 🚀 Features
- Random number generation
- Interactive user input
- Helpful hints (Too High / Too Low)
- Limited guessing attempts
- Simple and beginner-friendly interface

## 🛠️ Technologies Used
- C Programming
- Random Number Generation
- Loops and Conditional Statements
- Basic Input/Output Functions
